title: Can I return an espresso machine or grinder I already opened?
category: returns
---

Yes, within 30 days of delivery, as long as it works and comes back with all its parts. A 15% restocking fee is taken from the refund.

## Espresso machines

You can return an opened espresso machine even if you made a few drinks with it. Empty the water tank and drip tray, and let it dry before you pack it.

Send back everything that came in the box: portafilter, baskets, tamper, manual and the water filter if it had one.

## Grinders

Grinders are different. You can return an opened grinder only if no beans have gone through it. Once you have ground coffee with it, it counts as a used grinder and we can't take it back.

If you are having trouble with grind size, read "How to calibrate your grinder for espresso" before you decide to return it.

## If the machine or grinder is faulty

A faulty item is not a normal return, so there is no restocking fee. Contact us first, and if it is within the warranty, we repair or replace it.

## How to start

Start the return from Account > Orders. See "How do I return an item?" for the steps.
