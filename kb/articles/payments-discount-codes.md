title: How do discount codes work?
category: payments
---

Enter the code in the Discount code box at checkout. You can use one coupon per order.

## Rules

- One coupon per order. Codes can't be combined with each other.
- Codes can't be combined with the subscription discount.
- Codes can't be added after the order is placed. If you forgot a code, cancel the order while it can still be cancelled and order again.

## Discount codes and free shipping

Standard shipping is free on orders over $75 in the US, over C$100 in Canada and over £60 in the UK. We count the total after the discount, so a code can take your order below the free shipping amount.

If your cart is close to the amount for your country, check the total again after you apply a code.

## Why isn't my code working?

- It has expired or is for a different country's store.
- It needs a minimum order total.
- It excludes some items, such as machines on sale.
- You already have another code on the order.

The message under the Discount code box tells you which one it is.

## Codes for subscriptions

Subscriptions already have their own discount, so codes don't apply to them.
