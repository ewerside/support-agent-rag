title: Can I exchange an item for a different one?
category: returns
---

We don't do direct exchanges. Return the item within 30 days of delivery and place a new order for the one you want.

## Why we work this way

A return plus a new order is faster than an exchange. Your new item ships as soon as you order it, instead of waiting for the old one to reach us.

## Steps

1. Place a new order for the item you want.
2. Start a return for the old item in Account > Orders.
3. Send the old item back. You get a refund for it once it reaches our warehouse.

## A different color or size

The same steps apply if you want a different color of a machine or a different size of milk pitcher.

## Price differences

You pay the current price for the new item and get back what you paid for the old one. If the new item is cheaper, you end up paying less overall.

## Exchanging a faulty item

If the item is faulty, don't return it as a change of mind. Make a warranty claim instead, and we repair or replace it at no cost. See "How do I make a warranty claim?".
